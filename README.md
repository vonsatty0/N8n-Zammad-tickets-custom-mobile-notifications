# N8n-Zammad-tickets-custom-mobile-notifications
N8n automation for checking new tickets and their priorities in Zammad via API and pushing them to mobile device via custom HTTP POST notifications to **[ntfy.sh](https://play.google.com/store/apps/details?id=io.heckel.ntfy&hl=pl) app**.

You can set different ntfy.sh links for different priorities so you can set unique haptics and silent-mode rules in **[buzzkill](https://play.google.com/store/apps/details?id=com.samruston.buzzkill)** 
for example I use one link for low and normal prio that has minimum haptics and notifications gets ignored when phone is in silent mode, then i have two different links for high and critical priority with adequate haptics and silent-mode ignore rule for them, so no matter what i am doing at the moment, the critical and high priorities make an earthquake in my pocket with different sets of haptics so i can distinguish them without looking at the mobile device.
